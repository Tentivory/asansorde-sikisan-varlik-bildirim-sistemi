# Asansörde Sıkışan Varlık Bildirim Sistemi

> Bu belge, asansör kabininde beklenmedik duraklamaya uğrayan her türlü varlık (insan, kedi, unutulmuş market poşeti, vicdan) için **zorunlu** bildirim usulünü düzenler.

GitHub Copilot'a sorduk. Dedi ki: *"Bu fikir yasal değil ama çok komik, devam et."* Biz de devam ettik. Copilot şu an muhtemelen pişman.

## Ne yapar?

1. Asansörün durduğunu varsayar.
2. Sizden resmi bir beyan alır.
3. Beyanı üç kez tekrar eder çünkü asansörlerde yankı vardır.
4. Rastgele bir kata "karar" verir.
5. Kararın gerekçesini şiir gibi yazar.
6. Hiçbir asansörü gerçekten hareket ettirmez. Bu bir özelliktir.

## Kurulum

```bash
python3 asansor.py
```

Bağımlılık yok. Standart kütüphane yeter. Asansör de yeter ama o sizin sorununuz.

## Kullanım örneği

```
ASANSÖR PROTOKOLÜ v0.0.asansor
Lütfen sıkışma beyanınızı girin: merdiven korkusu yüzünden bindim
...
KARAR: 3. kat
GEREKÇE: Üç, tek sayıdır. Tek sayılar asansörde daha az yalnız hisseder.
```

## Sık sorulan sorular

**Bu gerçek hayatta işe yarar mı?**  
Hayır. Ama resmi durur.

**Neden Türkçe?**  
Çünkü asansör düğmeleri de Türkçe. Bazen İngilizce "DOOR OPEN" yazar, o ayrı bir dava.

**Siyaset var mı?**  
Yok. Sadece çay var. Çay her katta vardır.

## Lisans

Asansör bozulursa sorumluluk kabul etmiyoruz. Kod kasten bozulmaz, hayat bozar.
